O site no ar fica em https://www.legendarios3colinas.com.br, publicado pelo Atomicat.

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `index.html` | A página completa, com as fotos embutidas. É o código que vai no bloco **HTML personalizado** do Atomicat |
| `docs/COMANDO-PARA-O-CLAUDE.md` | Todos os dados oficiais, o comando para refazer ou ajustar a página com o Claude e o passo a passo para publicar |
| `previews/` | Imagens da página inteira no computador e no celular |
| `scripts/atualizar_pagina.py` | Script que gerou a atualização a partir do site antigo (TOP 1782 → TOP 1922) |
| `scripts/trocar_fotos.py` | Script que trocou as fotos da galeria e removeu os carimbos de TOP antigo |

## Como publicar

1. No Atomicat, abra a página e clique no bloco **HTML personalizado**, depois em **Editar código**.
2. Apague o conteúdo antigo e cole o conteúdo do `index.html`.
3. Em SEO, troque o título e a descrição para TOP 1922.
4. Publique.
